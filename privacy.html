개인정보 처리방침

1. 운영자와 적용 범위

DOGO는 대한민국에서 주성민이 운영합니다. 이 방침은 DOGO iOS 앱의 기기 내 데이터, 고객지원 이메일, 지원 웹사이트의 정보 처리를 각각 설명합니다. 개인정보 문의 담당자는 주성민이며, 연락처는 joosm21211@gmail.com입니다.

2. 앱에서 처리하는 정보

DOGO는 할 일과 처리 상태, 반복 일정, 시간표, 카테고리, D-Day, 목표, 집중 기록 및 앱 설정을 일정 관리와 기록 표시 등 앱 기능을 제공하기 위해 기기 내에서 처리·저장합니다. 이 앱 내부 데이터를 개발자 서버로 전송하거나 개발자가 자동으로 수집하지 않습니다.

DOGO는 회원가입, 광고·분석 SDK, 앱 자체의 클라우드 동기화 또는 앱 데이터를 외부 서버로 보내는 기능을 사용하지 않습니다. 사용자가 직접 보내는 문의 이메일과 웹사이트 방문 정보는 아래에서 별도로 설명합니다.

3. 저장 공간·위젯·알림·Live Activity

앱 데이터는 기기의 앱 저장 공간과 iOS App Group 공유 저장 공간에 보관됩니다. App Group은 같은 개발자의 DOGO 앱과 위젯이 같은 기기에서 데이터를 공유하는 저장 공간이며, 외부 업체에 앱 데이터를 제공하는 기능이 아닙니다.

알림은 기기에 예약하는 로컬 알림입니다. Live Activity는 집중할 일의 제목과 진행 시간 등을 iOS에 전달하여 잠금 화면 등에 표시합니다. DOGO는 이 기능을 위해 서버에서 보내는 푸시 알림을 사용하지 않습니다. 알림과 Live Activity의 허용 여부는 iOS 설정에서 관리할 수 있으며, 설정에 따라 일정이나 집중 제목이 잠금 화면에 보일 수 있습니다.

4. 기기 내 데이터의 보관과 삭제

기기 내 데이터에는 자동 만료 기간을 두지 않습니다. 일반 할 일, 시간표 일정, D-Day 등은 해당 화면의 삭제 기능으로 지울 수 있습니다. 일반 할 일을 삭제하면 그 할 일과 연결된 미루기 사본도 제거됩니다. 할 일을 삭제하더라도 이미 저장된 집중 기록까지 일괄 삭제되는 것은 아닙니다. 완료·취소·미루기와 목록 필터는 전체 기록의 삭제가 아닙니다.

“정해지지 않은 일”의 휴지통은 해당 항목을 목록에서 숨기는 기능입니다. 저장된 항목과 다른 날짜에 연결된 할 일을 보존하며, 영구 삭제 기능이 아닙니다. 집중 기록 등 모든 저장 항목에 개별 삭제 기능이 있는 것은 아닙니다.

앱 내 전체 데이터 초기화 기능은 제공하지 않습니다. 기기의 DOGO 앱과 관련 데이터를 제거하려면 iOS 설정 → 일반 → iPhone 저장 공간 → DOGO에서 “앱 삭제”를 이용하세요. “앱 정리하기”는 앱만 제거하고 문서와 데이터를 남깁니다. App Group 공유 저장 공간은 같은 그룹에 속한 앱이 기기에 남아 있는 동안 유지될 수 있습니다. 개발자는 기기 내 데이터에 접근하거나 이메일 요청으로 원격 삭제할 수 없습니다.

iCloud 또는 컴퓨터 백업을 사용하는 경우 설정에 따라 앱 데이터가 백업에 포함될 수 있습니다. 앱 삭제가 기존 백업까지 삭제하는 것은 아니며, 백업을 복원하면 이전 데이터가 돌아올 수 있습니다. 백업의 관리·삭제는 사용자가 Apple 또는 해당 백업 도구에서 해야 합니다. 이는 DOGO 자체의 클라우드 동기화와 구분됩니다.

5. 고객지원 이메일

이메일로 문의하면 발신 이메일 주소, 발신자 이름이 표시되는 경우 그 이름, 문의 내용과 직접 첨부한 자료를 받습니다. 기기 모델·iOS 버전·스크린샷 등은 사용자가 보내는 경우에만 받으며, 답변·오류 확인·후속 대응을 위해 이용합니다. 문의는 선택 사항이고 앱 이용에 필수적이지 않습니다. 문의에 필요하지 않은 개인정보나 민감한 내용은 보내지 마세요.

문의는 주성민만 일반 Gmail 계정으로 처리합니다. 자동 전달, 외부 상담 도구, AI 분석 및 첨부 자료의 별도 보관은 하지 않습니다. 답변·오류 확인·후속 대응이 끝나 더 이상 필요하지 않은 이메일과 첨부 자료는 지체 없이 삭제합니다. 메일함과 휴지통에서 해당 메시지 및 첨부 자료를 삭제하며, Gmail 자체의 처리·삭제 절차에는 Google 정책이 적용됩니다.

고객지원 메일의 수신·보관·회신에는 Google의 Gmail 서비스를 사용합니다. 사용자가 메일을 보내면 위에 설명한 발신자 정보, 문의 내용 및 첨부 자료가 인터넷을 통해 메일 서비스에서 처리됩니다. Google LLC 및 해당 계열사의 서비스는 전 세계 서버에서 운영되므로 거주 국가 밖에서도 정보가 처리될 수 있습니다. 이는 앱 내부 데이터의 자동 전송과 별개입니다. Google 측의 정보 처리 및 보관·삭제 절차는 아래 Google 개인정보처리방침을 확인하세요.

이메일 문의를 원하지 않으면 메일을 보내지 않고 DOGO의 기능과 앱 내 도움말을 이용할 수 있습니다. 이미 보낸 문의 정보에 대한 삭제 등 요청은 아래 7항의 연락처로 할 수 있습니다. 문의 정보는 광고·마케팅이나 이용자 추적에 사용하지 않습니다.

6. 지원 웹사이트

지원 웹사이트는 GitHub Pages에서 제공합니다. GitHub는 GitHub 로그인 여부와 관계없이 사이트 방문자의 IP 주소를 보안 목적으로 기록·보관한다고 안내합니다. 이러한 호스팅 정보 처리는 DOGO 앱 내부 데이터 처리와 별개이며, 보관 및 삭제 등은 GitHub의 개인정보 보호 정책에 따릅니다.

DOGO 지원 사이트에는 별도의 광고·분석 도구나 문의 수집 양식을 두지 않습니다. 선택한 표시 언어는 브라우저의 로컬 저장소에 보관되며, 이 언어값을 DOGO 운영자에게 전송하지 않습니다. 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.
